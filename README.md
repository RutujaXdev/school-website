# School Website

A responsive school website built with plain HTML and CSS.

## What it includes
- Hero banner with an illustrated misty-field scene
- Class and subject cards for primary, middle and secondary
- Computer lab section with a typing animation (CSS only)
- Notice board and FAQ
- Contact details

## Built with
HTML5 and CSS3 (no JavaScript)
